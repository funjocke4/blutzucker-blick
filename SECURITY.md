# Sicherheitsmeldungen

Dieses Projekt speichert sensible Gesundheitsdaten lokal auf dem Gerät.

- Bitte **keine** personenbezogenen Messwerte, echten Fotos von Messgeräten mit Seriennummern, PINs oder Zugangsschlüssel in öffentlichen GitHub-Issues posten.
- Eine private Kontaktmöglichkeit (z. B. GitHub Private Vulnerability Reporting) muss vor der Veröffentlichung eingerichtet werden. Bis dahin keine geheimen Daten an ein öffentliches Issue schicken.
- Sicherheitslücken und Datenverlust sind mit Priorität zu untersuchen.

Der Quellcode befindet sich im Veröffentlichungs-Vorbereitungsstand, ohne geprüften Sicherheits-Supportplan.
