# Testplan: Live-Ziffernerkennung (Build 45)

Nur Livekamera; der frühere Einzelfoto-Modus ist entfernt.

1. Display des Messgeräts in den gestrichelten Rahmen halten, vorzugsweise mit ausreichend Licht.
2. Kontrollieren, dass die großen Ziffern vollständig sichtbar sind.
3. Nachführen des Rahmens und Erkennung mit ruhiger bzw. leicht bewegter Hand vergleichen.
4. Erkannte Ziffern stets **am echten Display** kontrollieren, den Vorschlag ggf. bearbeiten, erst danach speichern.
5. Insbesondere testen: `3`/`5`, `0`/`8`, `1`/`7`, Werte mit zwei und drei Stellen, blinkende Bluetooth-Symbole, Spiegelungen.

Frühere lokal ausgewertete Ausschnitte: Beurer 135 mg/dL, Accu-Chek 112 mg/dL. Diese privat bereitgestellten Screenshots werden nicht in diesem Repository mitgeliefert. Die Bestätigung einer einzelnen funktionierenden Installation ist **kein** Ersatz für Gerätevalidierung.
