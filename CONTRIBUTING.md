# Mitmachen

Danke für dein Interesse an Blutzucker-Blick!

1. Ein Issue mit reproduzierbaren Schritten erstellen (ohne Gesundheitsdaten, echte Bluetooth-Adressen oder Zugangsdaten).
2. Änderungen im Branch vornehmen und Pull Request mit Beschreibung erstellen.
3. Falls möglich Gerät/Android-Version und reproduzierbare Testschritte nennen.
4. Für Beiträge am Projektcode gilt `GPL-3.0-only`, sofern keine abweichenden Rechte vereinbart wurden. Bitte nur Code und Grafiken einreichen, zu deren Veröffentlichung du berechtigt bist.

**Sicherheit/Medizin:** Keine Messwerte oder HbA1c-Schätzungen als Therapieempfehlung darstellen. Änderungen an Import, Berechnung oder Datenspeicherung sind besonders gründlich zu prüfen.
